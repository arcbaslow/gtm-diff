# Roadmap

Research and baseline: 2026-09-30. Base: `4dec665e7c8a529b1c33ec792d77481d9c7a1b93` (v0.1.0). This is an implementation order, not a release announcement. No version bump is part of this work.

CONTRIBUTING.md governs: v0.2 introduces a read-only `plan` that emits a plan file and nothing else; v0.3 is the earliest possible `apply`. The [plan design](designs/PLAN.md) is now available for review; neither command is implemented. No GTM access, credentials, network behavior in the comparison code, or export execution belongs in this work. Tests use synthetic local exports. Real, redacted exports are still needed to validate assumptions about the UI format.

Effort estimates include fixtures, tests and documentation: S = up to one day, M = two to four days, L = at least a week or a design decision. These are estimates, not measured delivery times. Risk describes compatibility and incorrect comparisons.

## Baseline and confirmed findings

On Windows, Node 24.19.0, npm 11.17.0: `npm ci` succeeded; typecheck, lint, format:check, all 30 tests and build passed. The first restricted install stalled and was stopped; the successful install used registry/cache access. No lockfile change was needed. See [verification](ROADMAP_VERIFICATION.md) for implementation results.

## Review workflows and comparable tools

These are documented capabilities checked on 2026-09-30, not a market-share survey or a claim that the tools were executed.

- Google's [publishing/version/approval workflow](https://support.google.com/tagmanager/answer/6107163?hl=en) provides workspace element differences and version history; formal approval requests are a Tag Manager 360 feature. Export-based Git review complements this workflow without credentials. A diff alone does not verify website runtime behavior.
- [vaidik/gtm-tools](https://github.com/vaidik/gtm-tools) is public source and documents live-account diff/copy/reset and list exports in JSON/YAML/CSV, with service-account credentials. Those live operations and environment overrides exceed this repo's offline scope. The inspected page did not expose a license; do not assume permission to reuse its code.
- [VollcomDigital/gtm-manager-boilerplate](https://github.com/VollcomDigital/gtm-manager-boilerplate) has an MIT license and documents a work-in-progress API-backed snapshot/diff/sync scaffold, JSON output, fail-on-drift and optional PR diff workflows. The relevant gaps here are structured output and integration recipes; its write paths are not a model for Now.
- [AdLint](https://github.com/ChristopherLandaverde/adlinter) is an open-source browser audit project documenting tracking checks, audit history and comparisons of audit findings. It offers rule-based review beyond this repo's semantic changes; that is a separate product decision, not evidence that a diff should score consent correctness.

CI recommendations are inferences from interfaces, not surveyed user requirements. [Git diff](https://git-scm.com/docs/git-diff#Documentation/git-diff.txt---exit-code) establishes opt-in 0/1 change signaling; [Actions](https://docs.github.com/en/actions/how-tos/create-and-publish-actions/set-exit-codes) treats nonzero as failure. Hence N5 adds a distinct operational error status while retaining existing drift signaling. Structured JSON (X4), escaped collapsible Markdown (N4/X7), deterministic files and explicit Action inputs/outputs (X6) let consumers avoid parsing terminal text. Actions should upload reports even when changes are detected, and separately propagate status 2 as a broken comparison.

## Open questions and rejected ideas

- Identity keys still use `::`. N3 rejects collisions within one export. A type string containing this delimiter can still collide across two files or display incorrectly; code inspection confirms the possibility, but valid GTM types containing it were not established. Decide encoding or rejection with real fixtures before changing the public key format (`src/core/identity.ts`).
- Leave normalization of empty versus absent fields, built-in display-name localization, container publicId/environment metadata, duplicate trigger names across different types and unresolved built-in trigger references unchanged until fixtures establish intended semantics. Name-only resolved references may conflate same-named triggers of different types; code inspection identifies the risk, but this run did not establish whether GTM permits that input.
- X2 uses structured type/name identities for newly normalized Parameter trigger references without changing the existing name-only reference arrays. Missing targets remain explicit unresolved IDs. Template-backed type strings and generated uniqueTriggerId values remain literal unless explicitly encoded as a trigger-reference Parameter; their cross-environment rules need real fixtures. See [sources and limits](PARAMETERS.md).
- Reject heuristic rename detection: CONTRIBUTING.md requires removed plus added. Never guess from similarity or IDs.
- Reject applying a raw microdiff as a v0.2 plan: stripped IDs, partial exports and ignored kinds make it incomplete. `plan` needs its own reviewed read-only file contract.
- Reject live API adapters, OAuth, synchronization and apply scaffolding in this branch, even where competitors offer them: explicitly outside authorization.
- Reject a wholesale schema-validation/runtime dependency or diff-engine rewrite for Now. Validate the structures actually consumed, preserve unknown values, and keep the runtime tree unchanged.
- Reject executing Custom HTML, Custom JavaScript, templates or export-supplied imports to infer equivalence. Compare inert data only (SECURITY.md).
- Defer a hosted review service and automatic PR comment posting: the local CLI should not transmit potentially sensitive exports. A separately configured CI integration may post an explicitly selected report later.
- Do not claim complete server support, browser-rendered Markdown verification or full resource validation from synthetic tests. Hosted Ubuntu/Windows Node 20/22/24 passed at merged base `c3b96ef`; [continuation verification](CONTINUATION_VERIFICATION.md) distinguishes that evidence from checks on the new branch.
